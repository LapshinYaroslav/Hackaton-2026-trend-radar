# Промпт подзапросов: турнир О1 и выбор subq-v4

Задачи О1 и О3, 27.09.2026. Код — `search/subqueries.py` (`PROMPT_VERSION = "subq-v4"`), шаг 2 режима «Запрос».

## Зачем

В медицинском ТОП-15 было много мейнстрима. Проверяли, можно ли увести подзапросы от устоявшихся разделов и общих
технологий одной формулировкой промпта.

## Метод

- **Варианты:** 11 системных промптов — V0 (действовавший `subq-v3`) и V1–V10 (якорь темы, примеры на посторонней
  теме, разложение по аспектам, два шага в JSON, роль аналитика, рыночные категории, стиль заголовков arXiv,
  самопроверка, явный запрет общих технологий, минимальный). Общий хвост требований 1–5 и формат JSON — одинаковые.
- **Генерация:** только английские подзапросы, 8 штук, `yandexgpt-5-pro`, температура 0.3 (повтор 0.8), без кэша;
  пользовательский промпт — `build_user_prompt` без изменений.
- **Темы (7):** ИИ технологии в медицине; технологии в ИИ; перспективные решения в финтехе; слабые сигналы в области
  кибербезопасности; роботы для промышленности; технологии в логистике; ИИ в образовании.
- **Прогон:** каждый вариант × тема — 2 запуска, 154 вызова, повторов не понадобилось, ошибок разбора 0.
- **Слепая разметка консультанта:** все подзапросы запуска 1, одинаковые строки внутри темы — одна; 433 уникальных
  подзапроса, без варианта, перемешаны (seed 42). Метки: `sub` — узкий класс технологий темы, недавний; `generic` —
  общая технология без привязки к теме; `adjacent` — смежная область; `established` — устоявшийся раздел или зрелая
  технология темы; `vague` — не класс технологий.
- **Автоматически:** нарушения формы (> 5 слов, цифры, кавычки, кириллица, запрещённые слова) и ошибки разбора;
  устойчивость — Жаккар множеств подзапросов между двумя запусками.

## Правило, заданное до запуска

По семи темам суммарно (запуск 1):
1. доля `sub` у победителя не меньше чем на 15 п.п. выше, чем у V0;
2. доля `generic` не выше, чем у V0;
3. нарушения + ошибки разбора — не больше 10 % подзапросов;
4. средний Жаккар — не ниже 0.2.

## Решение команды

Промпт подзапросов — **V2** (`subq-v4`), осознанное исключение из правила. V2 не выполнил правило 1, но по всем меткам
не хуже базы: по теме 91 % против 82 %, смежных 1.8 % против 8.9 %, «не технология» 5.4 % против 8.9 %, `sub` 14.3 %
против 8.9 %. Цена — один `generic` (1.8 % против 0 %), то есть формально нарушено и правило 2.

## Температура 0

С задачи О2 первая попытка идёт при температуре 0 (повтор — 0.8), температура входит в ключ кэша. Причина —
воспроизводимость, а не качество: у V0 при 0.3 Жаккар подзапросов между двумя запусками 0.175, то есть один и тот же
запрос давал заметно разные подзапросы и, как следствие, разный ТОП-15.

## Известные риски

- Примеры в промпте — про сельское хозяйство. При агротеме модель может повторить их дословно вместо поиска.
- Выбор сделан на 7 темах по одному запуску; разница с V0 — несколько подзапросов на вариант.
- Турнир шёл при температуре 0.3; при 0 подзапросы V2 другие, их качество отдельно не размечалось.
- Температура 0 у YandexGPT не гарантирует одинаковый ответ. Проверка О3 (5 тем × 2 запуска без кэша, 27.09.2026):
  4 темы совпали полностью, у «роботов для промышленности» английские наборы разошлись (общих 3 из 8), русские
  совпали. Одинаковый ТОП-15 на повторный запрос гарантирует кэш подзапросов, а не температура.
